# Dataset reference

Text2Floorplan documents two sources for its apartment geometry pipeline. ResPlan provides vector geometry and room graphs. RPLAN provides annotated floor-plan images. The pinned checkout contains the preprocessing source, six statistical files, and generated sample exports. Obtain raw inputs from the dataset authors under their applicable access and licensing terms.

- [ResPlan project, downloads and license](https://github.com/m-agour/ResPlan)
- [RPLAN author project and access information](https://ustc-gcl-f.github.io/projects/DeepLayout/index.html)
